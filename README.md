# Projeto X

Meu primeiro portfólio desenvolvido com HTML, CSS e GitHub.

## Sobre o projeto

Este projeto foi criado como parte de um desafio para praticar desenvolvimento web, organização de arquivos, versionamento com Git e publicação utilizando GitHub Pages.

O objetivo foi construir um portfólio pessoal simples, apresentando informações profissionais, habilidades e projetos.

## Tecnologias utilizadas

* HTML5
* CSS3
* Git
* GitHub
* GitHub Pages

## O que aprendi

Durante o desenvolvimento deste projeto, aprendi a:

* Criar páginas utilizando HTML
* Estilizar páginas com CSS
* Organizar arquivos de um projeto web
* Criar navegação entre páginas
* Utilizar Git para versionamento
* Publicar um site utilizando GitHub Pages
